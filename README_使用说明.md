# 技术部资料一键归档（Windows EXE 编译包）

本包用于通过 GitHub Actions 自动编译 Windows 独立 EXE。编译完成后，使用者电脑不需要安装 Python。

## 编译步骤

1. 登录 GitHub，创建一个新的空白仓库（Repository）。
2. 将本压缩包解压。
3. 将解压后的所有文件和 `.github` 文件夹上传到仓库根目录，确保目录结构如下：

   - `技术部资料一键归档.py`
   - `.github/workflows/build-windows.yml`

4. 提交到 `main` 分支。
5. 打开仓库的 **Actions** 页面，进入 **Build Windows EXE** 工作流。
6. 等待工作流显示绿色成功状态。
7. 在该次运行页面底部的 **Artifacts** 区域，下载 `技术部资料一键归档-Windows`。
8. 解压下载的文件，双击 `技术部资料一键归档.exe` 即可运行。

## 程序行为

- 选择一个资料文件夹。
- 先显示分类预览，用户确认后才移动文件。
- 未识别文件进入 `99_待确认`。
- 同名文件自动添加“副本”编号，不覆盖已有文件。
- 不删除文件。
- 只处理所选文件夹第一层的文件，不递归移动已有子文件夹。
- 程序异常时，会尝试在 EXE 同目录生成 `运行错误日志.txt`。

## 注意

首次整理前，建议先复制少量测试文件进行验证。分类依赖文件名关键词，分类不准确时应先调整关键词规则。
